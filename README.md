<h3>1. Что такое Python IDE Compile?</h3>
<p>Python IDE Compile - это компилятор Python с транслятором и с анализатором. Он умеет проверять синтаксис кода Python, искать ошибки и исправлять
  ошибки. Дает советы и исправляет неверный код на верный и профессиональный и еще умеет компилировать файлы Python. Он простой и удобный для работы с
веб-разработкой, разработкой ПО, разработкой машинного обучения, разработкой искусственного интеллекта и работой с анализами данных.</p>
<h3>2. На каком языке программирования разработан Python IDE Compile? И в какой среде разработки?</h3>
<p>Python IDE Compile разработан на языке Python и в среде разработки PyCharm</p>
<h3>3. Инструкция по вызову компилятора</h3>
<p>Чтобы вызывать компилятор для Python, следуйте по этим этапам</p>
<ul>
  <li>1. Скачайте наш ZIP-файл с исходным кодом в нашем репозитории на Github, чтобы компилятор смог найти Python-файл "compile.py". В этом файле
  содержится весь наш скрипт Python компилятора. Без этого файла, компилятор не сможет работать</li>
  <li>2. Скачайте JDK с официального сайта Adoptium. Ссылка на установку JDK: https://adoptium.net/temurin/releases/</li>
  <li>3. Скачайте Python с официального сайта Python.org. Ссылка на Python: https://www.python.org/downloads/. Если вы уже скачали
  Python перейдите к следующему этапу</li>
  <li>4. Запустите среду разработки VS Code или PyCharm. Если у вас нету этих сред разработки, вы можете их скачать</li>
  <li>5. Запустите терминал и введите такую команду: python compile.py</li>
  <li>6. Ознакомьтесь со с небольшой справкой и начните работу с компилятором Python IDE Compile</li>
</ul>
