<h3>1. Что такое PyCompile?</h3>
<p>PyCompile - это компилятор Python с транслятором и с анализатором. Он умеет проверять синтаксис кода Python, искать ошибки и исправлять
  ошибки. Дает советы и исправляет неверный код на верный и профессиональный и еще умеет компилировать файлы Python. Он простой и удобный для работы с
веб-разработкой, разработкой ПО, разработкой машинного обучения, разработкой искусственного интеллекта и работой с анализами данных.</p>
<h3>2. На каком языке программирования разработан PyCompile? И в какой среде разработки?</h3>
<p>PyCompile разработан на языке Python и в среде разработки PyCharm</p>
<h3>3. Инструкция по вызову компилятора</h3>
<p>PyCompile запускается из терминала командой Python. Перед запуском установите Python и JDK (компилятор javac должен быть доступен через PATH или JAVA_HOME). Скачайте ZIP-архив проекта и распакуйте его. В терминале перейдите в папку, где находится файл <code>compile.py</code>, например:</p>
<pre><code>cd путь\к\папке\PyCompile-master</code></pre>
<p>В примерах ниже вместо <code>python</code> можно использовать <code>py</code>, если так запускается Python в вашей системе. Чтобы посмотреть список команд и справку:</p>
<pre><code>python compile.py --help</code></pre>
<p>Основные команды:</p>
<ul>
  <li><strong>Проверить один или несколько Python-файлов:</strong>
    <pre><code>python compile.py check main.py
python compile.py check main.py utils.py</code></pre>
    Команда выводит найденные ошибки и предупреждения, советы по исправлению и техническую диагностику. Поддерживаются только файлы с расширением <code>.py</code>.</li>
  <li><strong>Показать безопасные исправления, не меняя файл:</strong>
    <pre><code>python compile.py fix main.py</code></pre>
    <strong>Применить найденные исправления к файлу:</strong>
    <pre><code>python compile.py fix main.py --write</code></pre>
    Перед сохранением команда показывает diff. Автоисправление ограничено заменой сравнения с <code>None</code> на <code>is</code>/<code>is not</code> и удалением пробелов в конце строк.</li>
  <li><strong>Перевести поддерживаемый Python-код в JavaScript:</strong>
    <pre><code>python compile.py translate main.py -o main.js</code></pre>
    Если не указывать <code>-o</code> / <code>--output</code>, результат выводится в терминал. Переводчик поддерживает только часть конструкций Python; неподдерживаемый код вызовет ошибку перевода.</li>
  <li><strong>Подключить короткую команду для дальнейших запусков:</strong>
    <pre><code>python compile.py connect
pycompile check main.py</code></pre>
    Если команда <code>pycompile</code> не найдена, добавьте указанную программой папку пользовательских <code>Scripts</code> в переменную <code>PATH</code>, затем откройте новый терминал.</li>
  <li><strong>Отключить короткую команду:</strong>
    <pre><code>python compile.py disconnect</code></pre></li>
</ul>
<p>Запуск <code>python compile.py</code> без команды выводит краткую справку. Если JDK не найден, установите его с сайта <a href="https://adoptium.net/temurin/releases/">Adoptium</a>, добавьте JDK в <code>PATH</code> или задайте <code>JAVA_HOME</code>, после чего перезапустите терминал.</p>
